# Attrappen erzeugen unter Linux

1. Datei „Splitting Trains - Attrappen erzeugen (Linux)“ herunterladen.
2. Einmal ausführbar machen: Rechtsklick → Eigenschaften → „Als Programm ausführen“ erlauben,
   oder im Terminal: `chmod +x "Splitting Trains - Attrappen erzeugen (Linux)"`
3. Starten (Doppelklick oder `./"Splitting Trains - Attrappen erzeugen (Linux)"`). Der Browser öffnet sich.
4. Züge anhaken, „Erzeugen“ klicken, Spiel neu starten.

Das Programm findet die Mod und die Züge selbst, auch im Proton-Ordner von Steam
(normale Installation, Flatpak und Snap). Wird ein Ordner nicht gefunden, kann man ihn
auf der Seite als eigenen Ordner hinzufügen. Einstellungen liegen in `~/.config/SplittingTrains`.
Noch nicht auf einem echten Linux-PC mit dem Spiel getestet, Rückmeldungen sind willkommen.

# Generating dummies on Linux

1. Download "Splitting Trains - Attrappen erzeugen (Linux)".
2. Make it executable once: right-click → Properties → allow "Run as program",
   or in a terminal: `chmod +x "Splitting Trains - Attrappen erzeugen (Linux)"`
3. Start it (double-click or `./"Splitting Trains - Attrappen erzeugen (Linux)"`). Your browser opens.
4. Tick the trains, click "Generate", restart the game.

The program finds the mod and your trains by itself, including Steam's Proton folder
(regular install, Flatpak and Snap). If a folder is not found, add it on the page as your own folder.
Settings are stored in `~/.config/SplittingTrains`.
Not yet tested on a real Linux PC with the game, feedback is welcome.
